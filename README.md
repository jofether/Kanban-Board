# Horizontal Kanban Board

A Vite + React + Tailwind demo that presents a horizontally scrolling Kanban board. The layout stresses a Vision Transformer to reason about columns that extend off-screen.

## Prerequisites
- Node.js 18+

## Setup
```bash
npm install
```

## Development
```bash
npm run dev
```
Then open the printed local URL (defaults to http://localhost:5173).

## Build
```bash
npm run build
```

## Preview production build
```bash
npm run preview
```
